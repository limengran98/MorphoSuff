The frozen representation pilot comprises six prespecified reporters, four representations and five held-out-gene folds (120 reporter–representation–fold results). Matrix values are arithmetic fold means and fold standard deviations. Paired contrasts were computed at reporter level, using the deposited reporter-hierarchical bootstrap intervals; the plotting code does not recompute or tune these intervals. The three phase crops are loaded from deterministic NumPy arrays and rendered with display limits in the frozen selection table. Crop selection is descriptive and does not enter any performance calculation. The comparison isolates the current representation boundary of this pilot: it does not establish an upper bound for raw phase images or compare all possible image encoders.
