# Supplementary Figure 1 source package

This is the complete audit behind the compact three-context summary in Figure 6f.
Panel a preserves the five frozen evidence criteria for every OPS reporter. Panel b
preserves the OASIS and PERISCOPE application rows, fold or screen estimates,
permutation controls, OASIS batch decisions and the four-dye substitution sensitivity
analysis.

OPS margins and the OPS row of the context-summary table describe the same coherent checkpoint-average median ensemble as Figure 6. Recovery is its arithmetic fivefold mean of endpoint-macro Pearson, not a median of scalar method scores. These two local tables are regenerated by `../final/figure6/code/rebuild_coherent_statistics.py`; the external evidence and replicates are unchanged. Routine Supplementary Figure 1 rendering remains panel-local.

The canvas is exactly 183 × 190 mm, with DejaVu Sans, 9 pt bold composite-only letters and a 6 pt ordinary-text floor supplied by `../publication_style.py`. No explanatory panel subtitles are drawn; concise context labels keep all gate rails clear.

Rebuild from the repository root with:

```powershell
cd paper/figure_sources/supplementary_figure1
./build.ps1
```

`build.ps1` first exposes the local packages under `paper/tools/`; an equivalent clean
environment can be created from `requirements-lock.txt` with Python 3.12.

The figure builder reads only four frozen, panel-local tables under `source_data/`
and does not fit models, change thresholds or reassign decision tiers. Three small
tables in `source_data/external_context/` additionally anchor Supplementary Tables
1 and 3 to the frozen admission counts and OASIS batch verdicts. It exports vector
PDF/SVG, a review PNG and a long-form table of the 52-by-5 OPS threshold margins.
The `external_context/` tables are immutable copies of the retained Figure 6f source
tables, included here to make the supplementary package self-contained.
Canonical outputs are written to
`published/SupplementaryFigure1.{pdf,svg,png}` and the PDF is synchronized to
`paper/figures/SupplementaryFigure1.pdf`.
