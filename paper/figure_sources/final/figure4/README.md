# Figure 4 — sealed reproducibility package

This folder is the complete, self-contained source archive for the approved
current Figure 4. It contains the frozen source tables and arrays, Python build
code and environment pins. The build writes standalone panels, the full
composite, automated QA and integrity manifests locally. Scientific inputs are
local; the shared typography module is required as described below. Rebuilding does not refit models or change any
statistical unit, case selection, model roster or aggregation rule.

## Rebuild everything

PowerShell:

```powershell
conda env create -f environment.yml
conda activate figure4-reproduction
.\build.ps1
```

With an existing compatible Python interpreter:

```powershell
.\build.ps1 -Python "C:\path\to\python.exe"
```

The build regenerates standalone panels a–d and the composite, runs the
scientific/output QA and the archive QA, and rewrites both package manifests.
After rebuilding, verify that local package with:

```powershell
python code/archive_manifest.py --verify
```

## Evidence sequence

The adopted visual sequence is:

1. information-intervention raincloud terrain;
2. residual-signal paired reporter barcode;
3. three frozen reconstruction modes with registered microscopy;
4. physical whole-screen transfer cases and all-method summaries.

Scientific inputs are contained in this Figure 4 directory. Typography also
requires `../../publication_style.py` and uses Matplotlib's bundled DejaVu Sans:
9 pt bold composite-only letters and at least 6 pt ordinary text. Native panels
are unlabelled. Explanatory panel titles
are removed. The effect axis includes every frozen reporter effect, and the
pRb image annotation is separated from gene labels and the identity line.
Rebuilds require renewed visual review; cross-platform PDF byte identity is not
guaranteed.

Expected outputs are editable PDF/SVG files and 600-dpi PNG previews for every
standalone panel and the final 183 mm × 225 mm composite.  The composite is
assembled from the same native Matplotlib artists as the standalone panels;
it does not paste panel PNGs.

## Integrity files

- `source_manifest_sha256.csv`: frozen `source_data/` identity used by the scientific QA.
- `artifact_manifest.csv`: output inventory regenerated by the existing Figure 4 verifier.
- `package_source_manifest_sha256.csv`: code, data and documentation hashes.
- `PACKAGE_MANIFEST.sha256`: hashes for every archived file except the manifest itself.

## Reconstruction display

Panel c contains three complete 1,000-gene response clouds. The pRb full-range
view retains extreme values, with a labelled 0–5 inset showing the crowded
origin. Statistics use the complete gene tables. Panel letters a, c and d
share a left alignment; the layout and text sizes are checked in the exported
figure and manuscript placement.
