# Figure 4c methods

The three reporters and displayed profiles are frozen selections. Profile
predictions are element-wise unweighted medians of ten aligned out-of-fold
predictions. Magnitude plots contain 1,000 held-out genes per reporter. Spearman
correlation quantifies magnitude ordering and the variance ratio quantifies
amplitude retention. Microscopy display limits and the selected pRb cell are
stored in the local manifests; the builder does not select a cell at run time.
