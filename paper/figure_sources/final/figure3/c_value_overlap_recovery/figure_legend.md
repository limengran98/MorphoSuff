Each point is one reporter. Horizontal position is marker information value, vertical position is undirected phase–marker overlap and colour is directed held-out-gene recoverability. The aligned forest reports reporter-level Spearman correlations between directed recovery and full-depth marker value, marker value at a matched observation depth, or phase–marker overlap. Horizontal intervals and the adjacent numerical rail report reporter-bootstrap 95% confidence intervals; all estimates use the same 52 reporters.
