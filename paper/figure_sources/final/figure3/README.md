# Figure 3 source package

This folder contains the source package for Figure 3: frozen source tables and microscopy arrays,
Python build code and environment pins. The build writes standalone panels, the
full composite, automated QA and integrity manifests locally. Scientific data
are local; typography requires the shared `../../publication_style.py` module.

## Rebuild everything

PowerShell:

```powershell
conda env create -f environment.yml
conda activate figure3-reproduction
.\build.ps1
```

With an existing compatible Python interpreter:

```powershell
.\build.ps1 -Python "C:\path\to\python.exe"
```

The build regenerates all three panels and the composite, runs the archive QA,
and rewrites both integrity manifests. After rebuilding, verify that local
archive with:

```powershell
python code/archive_manifest.py --verify
```

## Canonical outputs

- `a_recoverability_rank_atlas/figure/`: standalone panel a in PDF, SVG and PNG.
- `b_biology_endpoint_structure/figure/`: standalone panel b in PDF, SVG and PNG.
- `c_value_overlap_recovery/figure/`: standalone panel c in PDF, SVG and PNG.
- `composite/Figure3.*`: the approved 183 × 170 mm Figure 3 composite in PDF, SVG, PNG and TIFF.
- `qa/`: machine-readable and human-readable archive audit reports.

The standalone PDF/SVG panels are the canonical vector artwork. The composite
PDF/SVG is assembled from those vectors and preserves live text; PNG/TIFF are
the corresponding 600-dpi proof exports.
Native panels are unlabelled. Only the PDF/SVG compositors add 9 pt bold DejaVu
Sans letters; ordinary text is at least 6 pt. Raster proofs are rendered from
the labelled PDF. Explanatory panel headings are omitted.

## Frozen scientific contract

- Within each model, predefined folds or transfer directions are averaged arithmetically.
- Across the ten frozen predictors, the displayed consensus is the unweighted median.
- Q25–Q75 intervals in panel a describe model spread; they are not biological confidence intervals.
- Recoverability bands are descriptive: low, r < 0.60; intermediate, 0.60–0.75; high, r ≥ 0.75.
- Microscopy cards are frozen descriptive callouts selected independently of plotted scores.
- Endpoint-family results are the frozen endpoint audit, not a ten-model endpoint-level consensus.
- Panel a carries an entity-aligned biological-system strip beneath each of its
  nine rank spectra. Multi-reporter physical-screen tiles are subdivided when
  the screen spans more than one system; no dominant system is inferred.

## Integrity files

- `source_manifest_sha256.csv`: scientific CSV/NPZ input hashes regenerated by the main builder.
- `package_source_manifest_sha256.csv`: hashes for code, source data and archive documentation.
- `PACKAGE_MANIFEST.sha256`: hashes for every archived file except the manifest itself.

## Layout

- Panels have no explanatory headings; evaluation, axis and channel labels identify the displayed variables.
- Panel b labels biological systems and endpoint families; panel c includes quantitative annotations.
- Biological-system colour strips are present beneath all nine panel-a rank
  spectra.
- All three calibrated `20 μm` scale bars sit at the bottom-centre
  position in the reporter crops.
