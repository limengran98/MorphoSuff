# Supplementary Figure 4b methods

Each destination-screen point is the unweighted median of the ten benchmark method scores for the corresponding recovery or rank metric. These benchmark score medians are distinct from scores of the coherent response-replacement ensemble used elsewhere in Figure 6. Reporter diamonds then summarize medians across the observed destination-screen points.

The display adds a physical gutter to both ends of each metric axis, calculated
from the diamond's size and outline so that values near 0 or 1 remain fully
visible. The axes retain a linear scale, endpoint ticks at 0 and 1, and the
vertical 0.70 criterion identified by the shared category key. Native and
composite exports check the complete extents of every screen and median marker.

The analysis uses all 81 frozen directed reporter-to-destination-screen evaluations for the 34 reporters observed in more than one screen context. For each reporter and metric, pale points show destination-screen values, the horizontal segment spans the observed minimum and maximum, and the diamond is the reporter median. A reporter is `stable above` when every destination-screen value is at least 0.70, `stable below` when every value is below 0.70, and `crosses gate` when its observed range straddles 0.70. Recovery and magnitude-rank agreement are displayed separately. Reporter-group eta-squared values in the source summary are descriptive variance partitions, not causal estimates.
