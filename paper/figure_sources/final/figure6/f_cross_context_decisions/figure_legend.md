# Figure 6f legend

Measurement decisions in the OPS reporter atlas and external perturbation contexts.
Rails display the frozen pass/fail scale for recovery, response ranking, amplitude,
top-hit recovery and reliability. The OPS row shows the median across 52 reporters;
pale ticks show reporter-level values. Each external row is retained as its own
measurement context rather than treated as a biological replicate. Red rings
identify the first failed gate for each external readout. Counts beneath
the OPS gate summaries give the number of reporters
meeting each frozen criterion; the resulting tiers remain in the deposited source
table rather than being repeated as a separate display column.
External rows are descriptive context summaries and are not pooled as a formal
meta-analysis.
