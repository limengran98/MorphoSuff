# Study-owned code release statement

The study authors release the study-owned source code in this repository under
the MIT License, effective 12 August 2026. This authorization covers the
MorphoSuff reusable package, OPS dataset adapters, study-authored training and
evaluation runners, analysis workflows, figure builders, tests and
documentation committed to this repository.

On 12 August 2026, the study lead and repository owner explicitly confirmed
this public-release authorization. The authorization applies to the
study-owned code described above and to its future public maintenance in
`limengran98/MorphoSuff`; it does not alter upstream data or software terms.

Third-party software, pretrained weights and source datasets are not relicensed
by this statement. Their identities, pinned revisions and licence boundaries
are recorded in `THIRD_PARTY_NOTICES.md` and
`studies/ops/model_sources.yaml`. Files copied from third-party projects are
distributed only where their recorded licence permits redistribution.

The public `LICENSE` file is the operative grant for study-owned repository
code. This statement makes the scope of that grant explicit for reviewers,
archivists and downstream users.
