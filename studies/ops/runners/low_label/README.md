# OPS low-label benchmark runners

This directory releases the training code used for the OPS low-label
comparison. It contains the deterministic sampler, the specialist and shared
neural training loops, the classical/tabular runners, and the study adapters
for scButterfly, MIDAS, sciPENN and scPair. Data, predictions, checkpoints and
trained parameters are deliberately not copied into the repository.

The public facade is `run.py`. Its study implementations and local Python
dependencies are included in `legacy_exact/scripts`. Supply data and
reference locations through an untracked asset manifest.

## Methods

`methods.json` exposes Ridge, kNN, GBDT, CatBoost, MLP, TabM, ResMLP, MMoE,
MultiTab, scButterfly, MIDAS, sciPENN and scPair. The manuscript's frozen
ten-method roster is a subset of this extended low-label suite. MLP,
TabM, scButterfly and scPair are reporter-specific. ResMLP, MMoE, MultiTab,
MIDAS and sciPENN use the donor40/target12 transfer contract encoded by their
runner. All methods use the same held-out gene folds and exact label budgets.

## 1. Install and obtain public inputs

Install the repository with the model and OPS data extras:

```bash
python -m pip install -e '.[models,ops-data]'
```

Acquire OPS from the public sources recorded in
`studies/ops/data_sources.yaml`, verify the archive with
`reproducibility/ops/verify_acquisition.py`, and prepare the phase cache,
reporter-specific exact-pair H5 files and audit tables described in
`docs/ops_data_and_preparation.md`. The runner accepts those assets
at any location; their logical contracts are:

```text
phase_cache/                    indexed 172D phase cache and frozen folds
exact_root/*.exact.h5           exact paired reporter blocks
reporter_targets.csv            frozen 52-reporter registry
target_feature_dictionary.csv   observed endpoint registry
specialist_reference_root/      frozen outer-test identity reference
preprocessing_reference_root/   train-only preprocessing reference
```

Copy `assets.example.json` outside version control and replace the six common
OPS paths. Method-specific entries are checked only when that method is run:
`tabm_source` is required for TabM, while
`tabm_dependency_wheel` may remain empty when
`rtdl_num_embeddings==0.0.12` is already installed. The full-label reference
roots are generated by the corresponding full-label workflow; they contain
cohort identities and train-only preprocessing, not extra low-label
supervision.

For TabM, supply the official `tabm.py` from commit
`28e47ae301c92ec37787dde1ce923a0793f405b4`; its SHA-256 is checked against
`fc654af6a16bac53d893a8265c79d7af4ebddcb95ad0d600cc6b6bc6b7317ade`.
Install `rtdl_num_embeddings==0.0.12` or point the manifest to the original
checksummed wheel.

For scPair, place its public source at the path expected by the archived
source adapter:

```bash
git clone https://github.com/quon-titative-biology/scPair.git \
  studies/ops/runners/low_label/legacy_exact/external/original_methods/scpair
git -C studies/ops/runners/low_label/legacy_exact/external/original_methods/scpair \
  checkout --detach c585949ca8ea1314f5e68b260e3d9c5b2dabe61c
```

scButterfly, MIDAS and sciPENN execute through the included OPS study adapter
code. Their upstream identities remain recorded in
`studies/ops/model_sources.yaml`.

## 2. Freeze one shared sampling manifest

Build the nested 0.1%, 1%, 20% and matched 100% selections once, then give the
same directory to every runner:

```bash
python studies/ops/runners/low_label/build_sampling.py \
  --assets /path/to/ops_assets.json \
  --output-root /path/to/runs/low_label_sampling \
  --fractions 0.001,0.01,0.2,1.0 \
  --folds 0,1,2,3,4
```

Sampling is stratified by control status and gene, uses deterministic Hamilton
allocation, fits no quantity on the outer test, and stores exact phase/H5-row
identities for verification by each compatible method.

## 3. Inspect, smoke-test, and train

The side-effect-free dispatcher dry run prints the complete command and any
missing local assets:

```bash
python studies/ops/runners/low_label/run.py \
  --assets /path/to/ops_assets.json \
  --method catboost --fraction 0.01 --fold 0 \
  --sampling-root /path/to/runs/low_label_sampling \
  --output-root /path/to/runs/catboost/fraction_0.01/fold_0 \
  --dry-run
```

Remove `--dry-run` to execute. Use `--smoke` to exercise the model-native short
training/evaluation path where supported. Examples from each route are:

```bash
# classical/tabular target-only
python studies/ops/runners/low_label/run.py --assets ops_assets.json \
  --method gbdt --fraction 0.001 --fold 0 \
  --sampling-root runs/sampling --output-root runs/gbdt/f0

# shared donor40 -> target12 transfer
python studies/ops/runners/low_label/run.py --assets ops_assets.json \
  --method resmlp --fraction 0.01 --fold 0 \
  --sampling-root runs/sampling --output-root runs/resmlp/f0

# biological transfer
python studies/ops/runners/low_label/run.py --assets ops_assets.json \
  --method midas --fraction 0.01 --fold 0 \
  --sampling-root runs/sampling --output-root runs/midas/f0

# reporter-specific scPair; repeat over the frozen target12 registry
python studies/ops/runners/low_label/run.py --assets ops_assets.json \
  --method scpair --reporter lysosome_lamp1 --fraction 0.01 --fold 0 \
  --sampling-root runs/sampling --output-root runs/scpair/lamp1/f0
```

Additional native runner flags may be appended after `--`. All outputs are
written only to the caller-supplied run directory.

## 4. Release smoke checks

The static smoke is data-free:

```bash
python studies/ops/runners/low_label/smoke.py
```

With the model environment installed, add `--imports` to invoke `--help` for
all seven released entry points. `run_ops_low_label_classical_task.py
--self-test` additionally runs synthetic fits for the classical implementations.

The frozen campaign JSON files are stored under `legacy_exact/configs`.
`MIGRATION_MANIFEST.tsv` records source and package SHA-256 values for the
study implementations, including their public path/dependency bindings.
