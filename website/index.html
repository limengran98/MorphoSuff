01 / The approach

From prediction to
measurement decisions.

When a model stands in for a measurement, prediction accuracy is only one part of validation. MorphoSuff asks whether substituting its predictions preserves the intended analysis.

01

Define the use and reference

Specify the intended analysis and assess repeat measurements. A reliable reference is needed to judge an inferred readout.

02

Evaluate what prediction retains

Replace measured responses with predictions. Examine response ranking, amplitude, strong-hit selection and functional results.

03

Separate selection from evaluation

Apply fixed acceptance rules to calibration perturbations, then count supported successes, failures and missed uses on separate evaluation perturbations.

A decision that can be tested

Choose useful readouts,
then test the choice.

Across 260 OPS reporter–fold cases, ranking-based acceptance supported 204 successful prioritization uses, compared with 184 for Pearson-recovery-only acceptance, with 7 versus 8 supported failures.

Combining response criteria selected a smaller set: 170 successes and one failure, while missing 58 successful uses. Coverage and failure counts make that trade-off explicit.

What do the five decisions mean?

Quantitative proxy meets the study’s recovery, rank, amplitude and strong-hit criteria for a reproducible target.

Ranking proxy meets rank and strong-hit criteria for a reproducible target, but not all quantitative criteria.

Measurement required fails both proxy tiers despite a reproducible target, with recovery below the measurement-required cut-off.

Not identifiable has insufficient or unavailable reference-response reliability to establish sufficiency.

Unresolved has mixed or incomplete evidence under the reference decision rules.

What correlation can miss

A preserved ranking can hide
a compressed response.

Eleven reporters retain less than half the measured response-magnitude variance. A model can therefore preserve a useful ordering while losing the quantitative scale of a perturbation.

One dataset, more than one question. This focused analysis uses brightfield-DINO features to prioritize strong metabolic loss. The broader assessment uses CellProfiler-derived brightfield features to examine response ranking and amplitude. They evaluate different scientific uses with different representations.

Prediction agreement and task success can diverge

Two complementary examples.

A correlation score does not determine whether the strongest biological responses can be selected.

A successful target and a successful selection rule answer different questions. Across 20 Cell Health endpoint–context cases, calibration task evidence accepted three successful uses and two failures. Across all 978 LINCS probes, task-based acceptance did not consistently outperform recovery-only acceptance. The held-out evaluation shows where a rule identifies useful predictions and where its decisions still fail.
