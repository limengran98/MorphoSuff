# Project website

Static source for <https://limengran98.github.io/MorphoSuff/>.

To preview locally, run `python -m http.server 8000 --directory website` from the
repository root, then open <http://localhost:8000/>. No build step is required.

The site uses selected figure previews and reporter-level summary metrics.
Paper and figure downloads link to the final PDFs in `paper/` on the main branch.
GitHub Pages serves the site files from the root of the `gh-pages` branch.
